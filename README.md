# BudgetBuddy

BudgetBuddy is a personal expense tracker backend built with NestJS, Prisma, and PostgreSQL.

## Description

This project provides the backend services for managing personal finance data such as accounts, categories, and transactions.  
At the current stage, the backend includes:

- NestJS application bootstrap
- Prisma setup with PostgreSQL
- Accounts resource with CRUD structure
- Unit test stabilization with Prisma mocks
- E2E root route test alignment

## Tech Stack

- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL
- Jest
